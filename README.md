Music Player Project:

This is a responsive Music Player application built using HTML, CSS, and JavaScript. The project allows users to play, pause, and switch between multiple songs through a simple and interactive interface. It demonstrates how JavaScript can be used to control audio elements and dynamically update content on a web page.

Features:
Play and pause music,
Next and previous song navigation,
Dynamic song title updates,
Clean and user-friendly interface,
Responsive design for different screen sizes,
Interactive controls using JavaScript.
